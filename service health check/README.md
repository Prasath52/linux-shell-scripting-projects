# Service Health Check

## Overview

Checks whether a specified Linux service is running and reports its status.

## Features

- Service availability monitoring
- Timestamp reporting
- Can be scheduled through cron

## Service Checked

cron

## Sample Output

Sat Jun 6 20:15:16 IST 2026 - cron is running

## Skills Learned

- systemctl
- Service monitoring
- Shell scripting
- Linux administration
