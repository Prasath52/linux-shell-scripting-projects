# Linux Shell Scripting Projects

A collection of Linux shell scripting projects developed for learning Linux administration, automation, and monitoring concepts.

## Projects

### 1. Date Logger Automation
Automatically appends the current system date and time into a log file using cron scheduling.

### 2. Disk Usage Monitor
Monitors disk utilization and displays warnings when disk usage exceeds a predefined threshold.

### 3. Service Health Check
Checks whether a Linux service is running and reports its status with a timestamp.
