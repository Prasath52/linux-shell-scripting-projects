# Date Logger Automation

## Overview

This script appends the current system date and time to a log file.

## Objective

To understand Linux automation using cron jobs and file redirection.

## Features

- Captures current date and time
- Appends entries to a log file
- Runs automatically through cron scheduling

## Cron Schedule

*/15 * * * * /home/dmin/jobsearching/automate.sh

## Sample Output

Fri Jun 5 11:15:01 IST 2026
Fri Jun 5 11:30:01 IST 2026
Fri Jun 5 11:45:01 IST 2026
